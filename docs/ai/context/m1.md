## 关键 tradeoff 与坑（Windows 实测）

1. **FTS 中文搜索 = 大坑**：unicode61 tokenizer 对中日文整句当一个 token，子串查不到 → 换 **trigram**（>=3 字符子串匹配）。trigram MATCH 是 AND 语义（同一行须含全部 3-gram），查询词必须真实存在于某行；<3 字符降级 LIKE（%/_ 转义 + ESCAPE）。FTS 表 external content + triggers 自动同步。
2. **migrator 鸡生蛋**：查 meta 版本时表还不存在 → 空库视为 v0，001_init.sql 负责建表。
3. **meta 未提交丢失**：Project.create 的 executemany 不带 `with conn:` 事务 → 同连接可见但 close 后 reopen 读不到（测试暴露）→ 显式 commit。
4. **glossary 必须 UNIQUE(term)**：`ON CONFLICT(term)` 需要 term 上有唯一约束，否则 OperationalError。
5. **Repo.list 方法名遮蔽内置 list**：类方法 `list` 导致 mypy 把注解 `list[X]` 解析成方法 → 改名 `list_entries`。
6. **批量 vs 单条状态语义分离**：单条严格状态机逐级前进；批量允许任意目标但跳过 CONFIRMED（重翻工具）。
7. **locators_json 数组 vs Entry.locator 单数**：M1 桥接 = 单元素数组，首个即 Entry.locator；多位置合并走 M2 协议演进。

## Review 修复（2026-08-28 workflow 审查，14 个确认缺陷全部修复）

多维度代码审查（4 维度 × 对抗验证，27 agent）确认 14 个真实缺陷，全部修复并加回归测试（test_m1_fixes.py，13 用例）：

| 缺陷 | 修复 |
| :--- | :--- |
| **IR 稳定 ID 碰撞**：source[:256] 截断使共享前缀的长文本同 ID，upsert 静默覆盖已确认数据 | 改用完整 source 哈希（sha1 任意长度无成本差）；test_ir 契约同步改 |
| **迁移非原子**：executescript 隐式 COMMIT，中途失败留半成品库 | 脚本包 `BEGIN IMMEDIATE...COMMIT`（不能按分号拆分逐条——trigger 的 BEGIN/END 内含分号） |
| **未来版本无守卫**：旧二进制静默打开新版本项目，-32003 永不触发 | migrate 末尾校验 `version > max_known` 抛 MigrationError |
| **通知出错仍应答**：无 id 请求出错回 error，违反 JSON-RPC 规范且打乱响应流 | 异常分支也返回 None |
| **translation=null 无法清空**：显式 null 与未传被折叠 | repo.update 用 `_UNSET` 哨兵区分；`"field" in params` 传递 |
| **status=null 被静默接受**：协议 status 非空枚举 | params field_validator 拒绝显式 null |
| **glossary_upsert 过期 id**：冲突更新路径 lastrowid 陈旧 | 始终重查真实 id |
| **batch IN 超 32766 上限**：10 万条全选崩 | 分块 _CHUNK=500 |
| **status-only 更新触发 FTS 重索引**：批量改状态放大 O(n) FTS 写 | trigger 加 WHEN（仅 source/translation 变化同步） |
| **update 空操作刷 updated_at**：纯 id 请求伪造编辑时间 | 无实际变化不更新 |
| **file_path 过滤遇 malformed JSON 整页挂** | `CASE WHEN json_valid(...)` 坏行按无匹配 |
| **无参方法不校验**：core.ping 等多余字段放行 | 注册 EmptyParams（extra=forbid） |
| **entries.search 协议缺 page_size** | rpc-methods.json 补齐 + minimum/maximum |
| **result 裸 object 未引用模型** | project/entries/glossary result 引用 ProjectInfo/Page/ProjectStats/GlossaryEntry |

被拒的 finding：batch check-then-act 非原子（verify 判定——单连接串行模型下不真实，WAL 单写进程语义）。

**遗留（低优先级，记录不修）**：`<3 字符 LIKE 全表扫`（5 万条 <100ms 达标，未来大数据量可加 N-Gram 索引）；`file_path json_extract 无表达式索引`（M2 extract 落地时评估）。
