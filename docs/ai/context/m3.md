## 关键设计决策与坑

1. **asyncio 单事件循环 + 单 writer**（ADR-0007）：`serve_stdio` 保持同步签名（`asyncio.run`），
   现有测试/CLI 零改动；stdout 单 writer 队列保证 NDJSON 帧原子性。拒绝后台线程方案。
2. **通知不打断响应**：JSON-RPC 通知（无 id）经 `ctx['notify']` put_nowait 进 writer 队列，
   与响应共用单 writer，帧原子。测试 `test_notification_stream_keeps_framing_atomic` 锁定。
3. **CONFIRMED 竞态**：`upsert_translations` 的 ON CONFLICT UPDATE 带 `WHERE status != 4`，
   在**同一条 SQL 原子**完成，防「跨协程先查后改」把人工确认打回 MACHINE。translated 计数用
   实际更新行数（跳过的不计入）。
4. **serve EOF 杀任务**：asyncio.run 结束会取消未完成 create_task——`_serve_loop` EOF 后
   gather 等待后台任务收尾（真实 GUI 不触发；CLI 一次性脚本会等到翻译完）。
5. **插件契约演进**：api_version 精确相等 → major 匹配 + minor>=（1.1 兼容加载）；
   protect/restore feature-detect（缺省身份保护器）；PluginInfo.features 暴露。
6. **Model 响应三形态**：spike4 发现模型跟随 user JSON 模板——OpenAI 兼容 Provider 解析
   translations/items/顶层数组 + text/translation 字段都兼容（测试锁定）。
7. **Provider api_key**：环境变量注入为主（M4 钥匙串→spawn 时注入）；providers.test 可选
   参数覆盖；`_RpcLogger` 单点掩码防落盘泄露。
8. **断点续翻**：start 只选 translation is null 的条目（已翻自然跳过）；
   任务态在任务表（不进项目状态机）；取消批边界检查。
